## Підтверджені помилки

### 1. P2 — старий модуль дифтонгів може залишатися після оновлення сайту

Джерело: `sw.js:2`, `sw.js:49–58`; `index.html:6027` (підключення widget.js).

Service worker залишився `leren-be-v79`. Для JS, CSS, JSON і HTML віджета застосовано cache-first: якщо файл уже є в кеші, мережа взагалі не перевіряється. Адреси модулів не версіонуються. Користувач, який відкрив попередню версію дифтонгів 22 жовтня, після оновлення може продовжити отримувати старі файли, хоча основний index.html уже новий. Це не означає, що кожен новий користувач побачить проблему.

Виправлення: змінити версію SW/кешу разом із релізом і додати модулі до контрольованого списку ресурсів; надалі версіонувати файли або застосувати стратегію оновлення, яка перевіряє мережу.

### 2. P2 — годинник змінює хвилини й годину в різні моменти

Джерело: `index.html:2433` (вбудований srcdoc, фактично використаний застосунком); аналогічний код `modules/clock/widget.html:474–486`.

Хвилини округлюються до нуля вже з кута 345°, а година збільшується лише при фактичному переході через 360°. Відтворено виконанням саме вбудованого скрипту: початкове 14:55, попередній кут 330°, новий 350° → результат **14:00**, очікуваний після округлення **15:00**. Якщо відпустити стрілку в цій зоні, озвучення й перевірка відповіді працюють із неправильною годиною.

Виправлення: обчислювати загальну кількість хвилин із накопиченого кута й округлювати її єдиним кроком, включаючи перехід години та доби.

### 3. P2 — зміна мови дозволяє повторно отримувати бали за одне слово

Джерело: `modules/diphthongs/widget.js:1`, функції `setLanguage`, `render`, `answer`.

Після правильної відповіді `setLanguage()` викликає `render(false)`, який скидає `answered=false` і знову вмикає кнопки, але залишає вже нарахований `score`. Відтворено на одному слові: правильна відповідь → зміна мови → та сама відповідь → **20 балів за питання з максимумом 10**. Повторення дозволяє завищити фінальний результат і збережений рекорд.

Виправлення: відокремити переклад інтерфейсу від початку нового питання; при зміні мови зберігати стан відповіді, блокування кнопок і зворотний зв’язок.

### 4. P2 — нові віджети не використовують вибраний записаний голос

Джерело: `modules/diphthongs/widget.js:1`, `speak`; `index.html:2433`, вбудовані `speakCurrentTime` і `clockSpeakTarget`; окремий файл годинника `:529–536`, `:582–586`.

Обидва модулі викликають `speechSynthesis` напряму замість загального `say()`. Вибір записаного жіночого голосу Dena або чоловічого Arnaud у налаштуваннях на ці модулі не поширюється. Нові аудіофайли там не використовуються; результат залежить від системних голосів телефона. Годинник також озвучує після руху незалежно від глобального перемикача автоозвучення.

Виправлення: підключити модулі до спільного аудіосервісу; для iframe передавати запит на озвучення батьківському застосунку з перевіркою джерела повідомлення. Передбачити TTS для фраз без запису.

### 5. P2 — перемикання мови застосунку не перекладає нові уроки повністю

Джерело: `index.html:2433–2440`; `modules/diphthongs/widget.js:1`, `demos`, `artic`, `setLanguage`, `init`.

Годинник вбудований із `lang="uk"`, українськими кнопками та поясненнями, без прив’язки до `uiLang`. Дифтонги мають переклад частини інтерфейсу, але артикулятор, пояснення руху звуку й переклади слів залишаються українськими навіть після вибору English/Français/العربية у самому віджеті. Мова основного застосунку зчитується модулем лише під час початкової ініціалізації.

Виправлення: спільне джерело мови, оновлення модулів при її зміні та переклад усіх навчальних пояснень.

## Структура та підтримка

- Годинник зберігається двічі: окремий `modules/clock/widget.html` і великий екранований рядок `frame.srcdoc` в index.html. Сайт використовує рядок, тому редагування лише окремого файла не змінить урок. Копії вже відрізняються, зокрема текстом інтервалу перевірки. Варто залишити одне джерело або автоматично генерувати вбудовану копію.
