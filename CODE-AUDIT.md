# Перевірка коду — 22 жовтня 2026

## Виправлено

- **Втрата XP після ігор.** `gameDone()` нараховував бали в пам’яті, але не викликав збереження. Закриття застосунку до наступного збереження могло втратити ці бали. Тепер результат і тижневий бонус зберігаються одразу, індикатори оновлюються.
- **Повторні натискання в рольовій грі.** Правильну відповідь можна було натиснути кілька разів під час паузи, збільшивши лічильник і пропустивши репліки. Додано одноразове прийняття відповіді.
- **Переходи після виходу з гри.** Таймери рольової гри й Memory могли перемалювати екран після виходу. Тепер перевіряються поточна гра, екран і підключення відповідних DOM-елементів. При виході скидається активна гра; запізнілі відповіді AI також відхиляються наявною перевіркою ідентичності стану.
- **Некоректні дані хмарного прогресу.** Невдале читання JSON раніше залишало порожній об’єкт, який міг замінити локальний прогрес. Некоректний JSON, null, масиви й примітивні значення більше не застосовуються.
- **Імпорт прогресу.** Масив замість об’єкта карток, некоректні записи, від’ємні або нескінченні бали відхиляються до зміни поточного прогресу.
- **Сервер AI.** Коректний JSON із тілом null або масивом спричиняв неконтрольовану помилку до обробника винятків. Тепер такі запити отримують HTTP 400.
- **Доступність Toets.** Область пояснення позначається `role=status` до додавання відповіді.
- **Повторні запити сповіщень (попереднє виправлення).** Фонова синхронізація не створює підписку і не запитує дозволу. Створення можливе лише через явне увімкнення нагадувань.

Версію офлайн-кешу піднято до `v79`. Версію AI worker піднято до `2026-10-22.1`.

## Перевірено

- Синтаксис основного JavaScript, service worker і всіх 6 допоміжних JS/MJS-файлів.
- 762 навчальні картки: унікальні ID та наявність nl/en/fr/uk/ar.
- Наявність усіх 20 ресурсів офлайн-кешу, іконок і скриншотів маніфесту.
- JSON словника, бази знань і маніфесту; відсутність повторних HTML ID.
- Записані аудіофайли: усі 4605 записів чоловічого й 4600 жіночого маніфестів існують локально; повторних хешів немає.
- Автоматичні перевірки збереження XP, одноразового тижневого бонусу, повторних натискань, відкладеного переходу після виходу, захисту локального прогресу, некоректних запитів AI.
- 12 сценаріїв дозволів/наявності підписки/стану нагадувань.

Запуск перевірок (Node.js):

```sh
node tests/code-audit.cjs
node tests/push-permissions.cjs
```

## Межі перевірки

Це перевірка коду, даних і регресійних сценаріїв, а не гарантія відсутності всіх помилок. Мобільні дозволи, фактична доставка push, голоси пристрою, Google/Firebase-вхід і синхронізація між реальними пристроями потребують перевірки на пристроях після публікації. Офлайн-ресурси перевірено на наявність, без імітації повного мережевого відключення.

Наявний ручний експорт прогресу містить лише бали та стан карток; рекорди Toets, ігри та налаштування до нього не входять. Це обмеження поточного формату резервної копії.

Зміни локальні. Сайт та AI worker ще не опубліковані. Сторонні зміни аудіофайлів не редагувалися.
