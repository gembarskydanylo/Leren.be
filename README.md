# Polyglot Leren — Nederlands A1.1 🇳🇱🇺🇦

Інтерактивний тренажер нідерландської A1.1.  
Мови інтерфейсу: українська · англійська · французька · арабська.

## Контент

- **≈ 437+ карток**
- **≈ 92 речення** у «Складанні»
- Новий розділ **«Робота та банк»** (20 карток)
- Дієслова: ~60
- Їжа / покупки: 38
- Годинник 15 · Транспорт 18 · Лікар 15 · Фрази 25

## Можливості

Вивчати · Тест · Аудіювання · Повторити · Складання (3 рівні)  
Дизайн Oranje Pop · PWA · прогрес у браузері · озвучування

python3 -m http.server 8000
