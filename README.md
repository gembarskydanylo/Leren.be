Інтерактивний тренажер нідерландської A1.1.

## Нове: режим Toets A1

Чотири повноцінні міні-тести (по 12 питань) у стилі CVO / inburgering:
- Multiple choice (словник, граматика, фрази)
- Aanvulzinnen / gap-fill
- Коротка leesvaardigheid (текст + питання)
- Підрахунок балів, зворотний зв’язок, поріг «склав» ≥70%
