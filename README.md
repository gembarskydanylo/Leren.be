# Polyglot Leren — Nederlands A1.1 🇳🇱🇺🇦

Інтерактивний застосунок для практики нідерландської мови рівня A1.1. Інтерфейс підтримує українську, англійську, французьку та арабську мови.

## Можливості

- Вправи, картки, аудіорежим і повторення вивчених слів.
- Практика нідерландських артиклів `de` / `het`.
- Режим «Складання»: окремі набори речень для шести основних розділів.
- Три рівні складності: 8, 10 або 12 завдань за раунд; на складніших рівнях є зайві картки-слівця.
- Збереження прогресу та налаштувань у браузері.
- PWA-маніфест і сервіс-воркер для кешування основного застосунку та запуску офлайн після першого успішного завантаження.
- Адаптивний інтерфейс і світла/темна тема (дизайн «Oranje Pop»: помаранчеві акценти, нижня панель режимів).

## Запуск локально

Можна відкрити `index.html` напряму для базового використання. Для встановлення PWA та перевірки офлайн-режиму потрібен HTTPS або локальний вебсервер (наприклад, `python -m http.server 8000`).

## GitHub Pages

У налаштуваннях репозиторію відкрий **Settings → Pages**, вибери гілку `main` і папку `/ (root)`. Файли PWA використовують відносні шляхи, тому працюють у проєктному каталозі GitHub Pages.

Після першого відкриття сайту онлайн дочекайся завершення завантаження та кешування. Офлайн-поведінку перевір у браузері, вимкнувши мережу й перезавантаживши сторінку. Деякі браузери можуть вимагати повторного відкриття сайту або встановлення PWA перед повною офлайн-перевіркою.

## Android / APK

Для Android можна обгорнути вебзастосунок у Capacitor. Потрібні Node.js та Android Studio/Android SDK. APK у цьому архіві ще не зібраний — його треба зібрати та перевірити окремо.
