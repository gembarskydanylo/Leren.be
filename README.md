# Leren.be — Nederlands A1.1 🇧🇪🇺🇦

Інтерактивний тренажер нідерландської мови рівнів A1.1 і A1.2 для українців (пояснення також англійською, французькою та арабською).

**Сайт:** https://lerenbe.com/

## Що всередині
- **Два рівні:** A1.1 (≈ 550 карток, 27 тем) і A1.2 (≈ 135 карток, 12 тем: мій день, модальні дієслова, perfectum, житло, телефон і лист, граматика 2)
- **Прогрес:** бали, шкала до наступного рівня, відкриття рівня балами або тестом на рівень, ціль дня та серія днів 🔥 (див. `LEVELS.md`)
- **Екрани:** нижня панель з 5 розділів — Урок · Ігри · Toets · Словник · Прогрес. Урок відкривається одразу: тема вгорі («Змінити» відкриває вибір рівня, розділу й теми), під нею режими Вчити · Тест · Слухати · Речення · Повтор
- **Шапка:** 🔥 серія, ⭐ бали і ⚙ Налаштування (мови, голос, автоозвучення, темна тема, ціль дня, інструкція)
- **Перший запуск:** питання «З чого почнемо?» (A1.1 або тест на рівень A1.2) і покрокова інструкція (10 кроків, 4 мови)
- **Ріст:** «Поділитися» результатом Toets (картинка + текст), прохання оцінити в Google Play у застосунку для Android (після 3 днів серії або складеного Toets; пакет задається константою `PLAY_PACKAGE`)
- **Дієслово в історії** — вправа як на аркуші «Een dag van …»: історії «Een dag van Taras», «Het weekend van Oksana» і «Een dag van Mykola» (57 пропусків, один суцільний текст із номерами), правила -t / -en, z→s, v→f, heeft, dt
- **Ігри:** Діалог-пазл і Рольова гра (7 побутових діалогів: кіно, море, пекарня, лікар, знайомство, автобус, школа; рівні «вибрати / скласти / сказати в мікрофон»), «Відповідай на питання» (18 питань з уроку, голосом — перевірка «ik» + форма дієслова + частка в кінці), Бліц 60 с, Memory, Диктант, «Мій день» (інверсія «Om 7 uur sta ik op»), виклик тижня (5 ігор → +100)
- **Kort / lang** — гра як на дошці в класі: дві колонки KORT і LANG, рівні «1 склад», «2 склади» та «Дієслово» (ik slaap — wij slapen, ik zwem — wij zwemmen), таблиця правила
- **Дифтонги: Звукова гірка** — Toets → A1.1: теорія з озвучуванням, 10 випадкових слів із 22, пояснення чотирма мовами. Рекорд і XP використовують спільну систему Toets; XP нараховується лише за покращення рекорду. Код і дані в `index.html` (блок `DIPH_UI` / `DIPH_WORDS`), доступний офлайн.
- **Toets** — 4 міні-іспити A1.1 і 2 іспити A1.2 по 12 питань, плюс тест на рівень A1.2 (15 питань) у стилі CVO / inburgering (вибір відповіді, вставити слово, читання), поріг «склав» ≥ 70 %
- Озвучування через синтезатор мовлення пристрою; світла й темна теми «Oranje × België» з об'ємними кнопками (див. `DESIGN.md`)
- Працює офлайн (PWA), прогрес зберігається лише на пристрої

## Застосунки для Android та iOS
Сайт підготовлено для пакування через [PWABuilder](https://www.pwabuilder.com/): вкажи адресу сайту → **Package for stores**.
- **Android (Google Play):** пакет TWA. Після створення PWABuilder дасть файл `assetlinks.json`. Він має лежати в корені домену: `https://gembarskydanylo.github.io/.well-known/assetlinks.json`, тобто в окремому репозиторії `gembarskydanylo.github.io` (або на власному домені, якщо його підключити). Без цього файлу застосунок працюватиме, але з адресним рядком браузера вгорі.
- **iOS (App Store):** пакет Xcode-проєкту; збирається на Mac з обліковим записом Apple Developer.
- Політика конфіденційності для магазинів: `https://lerenbe.com/privacy.html`

## Записане озвучення (замість голосу телефона)
Застосунок спочатку шукає готовий файл `audio/nl/<hash>.m4a`; якщо його немає — читає голосом пристрою.
1. Потрібен ресурс **Speech** в Azure (тариф Free F0) і його ключ (Keys and Endpoint → KEY 1). Ключ нікуди не комітити.
2. У Терміналі з папки репозиторію: `AZURE_SPEECH_KEY=… AZURE_SPEECH_REGION=northeurope bash tools/make-audio-azure.sh` (голос за замовчуванням Arnaud; жіночий — `VOICE=nl-BE-DenaNeural`). Безкоштовний тариф дає ~20 запитів на хвилину, тож усе займає кілька годин; якщо скрипт зупиниться — запусти ще раз, він продовжить.
3. Завантаж папку `audio/nl` на GitHub.
Після додавання нових слів: `node tools/collect-audio-texts.js` (потрібен локальний сервер на :8765), потім знову крок 2.

## Щоденні нагадування (push)
Як працює: користувач сам вмикає «Нагадування» в ⚙ Налаштуваннях і вибирає годину. Підписка зберігається у Firebase Firestore (колекція `subs`). Робочий процес `.github/workflows/reminders.yml` щогодини запускає `tools/send-reminders.mjs`: тим, у кого зараз вибрана година і ціль дня ще не виконана, надходить одне сповіщення на день (зі згадкою серії 🔥, якщо вона жива). Протерміновані підписки видаляються самі.

Налаштування (один раз):
1. https://console.firebase.google.com → **Add project** (безкоштовний план Spark, Google Analytics не потрібен).
2. **Build → Firestore Database → Create database** (production mode, регіон `eur3` або `europe-west1`). Вкладка **Rules** → встав вміст `firestore.rules` → **Publish**.
3. **Project settings → General → Your apps → Web (</>)** → зареєструй застосунок → скопіюй `projectId` і `apiKey` у `PUSH_CONFIG` в `index.html`.
4. **Project settings → Service accounts → Generate new private key** → JSON-файл.
5. GitHub → репозиторій → **Settings → Secrets and variables → Actions → New repository secret**:
   - `FIREBASE_SA` — увесь вміст JSON-файлу;
   - `VAPID_PUBLIC` — публічний ключ (такий самий, як `vapid` у `PUSH_CONFIG`);
   - `VAPID_PRIVATE` — приватний ключ (зберігай лише в секретах).
6. **Actions → Daily reminders → Run workflow** — перевірка (у журналі: `checked …, sent …`).

Поки `projectId`/`apiKey` порожні, перемикач нагадувань не показується, і жодні дані нікуди не надсилаються.
У Google Play → «Безпека даних»: «Ідентифікатори пристрою або інші ідентифікатори» — збираються, необов’язково, не передаються третім особам, користувач може видалити (вимкнувши нагадування).

## Словник (Woordenboek)
- Дані: `dict/src/*.tsv` (формат `lemma|de/het|множина|частина мови|рівень 1=A1 2=A2|uk|en|форми|приклад nl|приклад uk`), збірка: `node tools/build-dict.mjs` → `dict/nl.json`.
- Форми слів (дієвідміна, множина, прикметники) і пошук: `tools/dict-engine.js` — та сама логіка вбудована в `index.html` (блок DICTIONARY ENGINE).
- Поле `форми`: `sep=op` (відокремлюваний префікс), `aux=z` / `aux=hz` (perfectum із zijn / hebben або zijn), `part=…` (свій дієприкметник), `cmp=beter,best` (неправильне порівняння).

## Perplexity (пошук в інтернеті для Claude Code)
Офіційний MCP-сервер Perplexity ([perplexityai/modelcontextprotocol](https://github.com/perplexityai/modelcontextprotocol)) підключено у файлі `.mcp.json`. Ключ у репозиторії НЕ зберігається — його бере зі змінної середовища:
```
export PERPLEXITY_API_KEY="pplx-..."   # ключ з https://console.perplexity.ai
cd ~/Documents/Leren.be && claude      # Claude Code сам запропонує увімкнути сервер perplexity
```
