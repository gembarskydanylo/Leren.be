## Navigation and learning contract

Home -> start/resume the exact saved lesson; or All topics -> A1.1/A1.2 -> chapter -> lesson.
Placement remains optional and does not mark preceding lessons as completed. A saved placement check is resumed through the main home action. Completing all lessons produces an all-complete action rather than starting lesson one again.

- Orange Ukrainian cat remains the main learner/companion. Peter and Dafna remain teachers. The cat still responds to a tap.

- No new network dependency, third-party UI library or storage key. Existing topic illustrations and cat artwork are reused.
