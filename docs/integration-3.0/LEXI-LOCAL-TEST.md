# Lexi — локальне тестове середовище з справжнім AI

Реліз 263 і **запропонований** Lexi Worker (`docs/integration-3.0/ai-worker.lexi-proposed.js`, без змін) працюють
**лише на твоєму Mac**. Нічого не розгортається. Production-Worker `leren-ai`, lerenbe.com, Firebase і їхні ключі не
використовуються.

| Що | Як |
|---|---|
| Застосунок 263 | `http://localhost:8080` (на Mac) або та сама адреса на Samsung через USB |
| Worker | працює всередині `tools/lexi-local.cjs`; KV і ліміти в пам'яті, ті самі числа, що в `wrangler.toml` (12 / 40 / 300 за хвилину, 60 на пристрій за день) |
| AI | твій **окремий тестовий ключ** Anthropic, або mock-відповіді без ключа |
| Захист витрат | не більше 150 викликів моделі за запуск (`LEXI_MAX_CALLS`), токени друкуються після кожного виклику |

## 1. Тестовий ключ (один раз, ≈ 3 хв)

1. Відкрий [console.anthropic.com](https://console.anthropic.com) → **API keys** → **Create key**, назва `lerenbe-lexi-test`.
   Production-ключ Worker не використовуй.
2. **Limits / Billing**: постав місячний ліміт витрат, наприклад $5. Повна перевірка (крок 4) — це 16 викликів, кілька
   центів.
3. Скопіюй ключ. Його ніде не треба зберігати: сервер питає його при запуску прихованим полем.

## 2. Запуск

Потрібна копія гілки (якщо ще немає):

```bash
git clone --quiet --branch integration/lerenbe-3.0 https://github.com/gembarskydanylo/Leren.be.git /tmp/lerenbe-263
```

Запуск сервера (термінал не закривай):

```bash
cd /tmp/lerenbe-263 && git pull --quiet && node tools/lexi-local.cjs
```

На запит `TEST Anthropic key` встав ключ і натисни Enter (символи не показуються). Якщо просто натиснути Enter,
середовище запуститься з mock-відповідями, без AI і без витрат.

Ключ лишається тільки в пам'яті цього процесу: він не друкується, не записується у файли й не потрапляє в історію
терміналу. Після `Ctrl+C` його немає.

## 3. Відкрити застосунок

- **На Mac.** У Chrome відкрий `http://localhost:8080/__lexi-local`. Сторінка один раз направляє застосунок на
  локальний Worker і відкриває його.
- **На Samsung.** Під'єднай телефон за кроком 0 інструкції [SAMSUNG-TEST-CHECKLIST.md](SAMSUNG-TEST-CHECKLIST.md).
  Порт той самий: `8080` → `127.0.0.1:8080`. На телефоні відкрий `http://localhost:8080/__lexi-local`.

Далі все як у звичайному застосунку: згода на AI, Lexi, Lesson Help, говоріння. Відповіді справжні, від тестового ключа.
У терміналі видно кожен виклик моделі й токени.

## 4. Автоматична перевірка відповідей (16 запитів)

Поки сервер працює зі справжнім ключем, у **другому** вікні терміналу:

```bash
cd /tmp/lerenbe-263 && node tools/lexi-live-check.cjs
```

Що перевіряється:
- мова пояснень: українська, арабська, французька;
- персона Lexi, а не Peter, і що вона каже, що це AI;
- виправлення помилки та відсутність виправлення правильного речення;
- граматика de/het і A2.1;
- Lesson Help до і після відповіді;
- атака через профіль;
- запит не про мову;
- рольова гра;
- курс FR.

Скрипт пише звіт `lexi-live-report-….md` з усіма відповідями. Автоматичні позначки — лише підказки, остаточна оцінка —
прочитати відповіді. Звіт можна передати Claude для розбору.

## 5. Зупинити

У терміналі сервера натисни `Ctrl+C`: він покаже, скільки було викликів і токенів. Якщо ключ більше не потрібен,
видали його в Anthropic Console.

## Чим це відрізняється від production

Ці пункти перевіряються лише після розгортання Worker (README, розділ 3):
- справжні ліміти Cloudflare і заголовки мережі;
- Origin: локальний сервер передає Worker `https://lerenbe.com`, бо Worker обслуговує лише цей сайт;
- push, вхід, синхронізація й App Check працюють тільки на lerenbe.com.
