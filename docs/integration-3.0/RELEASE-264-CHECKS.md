# Реліз 264 — ручні перевірки перед злиттям

Дві перевірки, які не можна зробити автоматично:
- А — телефон Samsung;
- Б — справжній AI.

Обидві запускаються з Mac. Production (lerenbe.com, Worker, Firebase) не зачіпається.

## А. Samsung: оновлення 263 → 264 (≈ 30 хв)

Підготовка телефона, USB і Port forwarding — як у розділі 0 [SAMSUNG-TEST-CHECKLIST.md](SAMSUNG-TEST-CHECKLIST.md). Відрізняються лише копії сайту.

1. Скопіюй обидва релізи в тимчасові папки:

```bash
git clone --quiet https://github.com/gembarskydanylo/Leren.be.git /tmp/lerenbe-263-check
```

```bash
git clone --quiet --branch audit/lerenbe-3-0-quality https://github.com/gembarskydanylo/Leren.be.git /tmp/lerenbe-264-check
```

2. Запусти **263** і відкрий на телефоні `http://localhost:8080/`:

```bash
cd /tmp/lerenbe-263-check && python3 -m http.server 8080 --bind 127.0.0.1
```

3. У 263 підготуй старі налаштування:
   - **Налаштування → Вчитель → Dafna**;
   - пройди один урок і запам'ятай кількість XP;
   - відкрий історію «Een dag in België».
4. Зупини сервер (Ctrl+C) і запусти **264** на тому самому порту:

```bash
cd /tmp/lerenbe-264-check && python3 -m http.server 8080 --bind 127.0.0.1
```

5. На телефоні онови сторінку, потім закрий і знову відкрий вкладку. Перевірити версію можна на Mac: `chrome://inspect` → **Inspect** → Application → Cache storage. Там має бути `leren-be-v264`, а не `leren-be-v263`.

| # | Що перевірити | Очікується |
|---|---|---|
| 1 | XP, пройдений урок | Ті самі, що в 263 |
| 2 | Налаштування | Рядка «Вчитель» немає, порожніх місць немає. Рядок голосу показує **голос Dafna** |

## Б. Справжній AI (платні запити, ≈ 28 викликів моделі)

Потрібен **тестовий** ключ Anthropic з лімітом витрат (console.anthropic.com → API keys / Limits). Ключ вводиться прихованим полем, не друкується і не записується у файл. Нікому його не пересилай.

1. У папці гілки запусти локальне середовище (Worker із цієї гілки, модель за замовчуванням Worker):

```bash
cd /tmp/lerenbe-264-check && node tools/lexi-local.cjs
```

   Встав тестовий ключ, коли його попросять. Порт 8080 має бути вільний: спершу зупини `http.server` з частини А.
2. У другому вікні терміналу запусти набір релізу 264 (28 сценаріїв: uk/en/fr/ar × nl/en/fr × A1.1–A2.1 × 5 режимів):

```bash
cd /tmp/lerenbe-264-check && LEXI_SET=264 node tools/lexi-live-check.cjs lexi-live-264.md
```

3. Звіт буде у файлі `lexi-live-264.md`. На що дивитися:
   - `reply_type`: чи правильно модель визначає тип відповіді, а отже й кнопку під нею;
   - `explain`: пояснення мовою інтерфейсу на питання про мову;
   - Lesson Help до відповіді: розв'язок не видається;
   - Lexi ніколи не називає себе Peter або Dafna.

   Автоматичні позначки CHECK — лише підказки. Остаточну оцінку дає прочитання відповідей.
4. Додатково (той самий ключ, ~16 викликів) — загальний набір:

```bash
cd /tmp/lerenbe-264-check && node tools/lexi-live-check.cjs lexi-live-general.md
```

**Критерій для злиття:**
- у пункті 3 немає видачі розв'язку і немає персони Peter або Dafna;
- щонайменше 24 з 28 сценаріїв мають правильну кнопку;
- пояснення мовою інтерфейсу є в усіх сценаріях «питання про мову».

Після перевірки зупини сервер (Ctrl+C) і, якщо хочеш, видали тестовий ключ у консолі Anthropic.
