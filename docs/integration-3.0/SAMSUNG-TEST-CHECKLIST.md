# LerenBe 3.0 (реліз 263) — ручна перевірка на Samsung

Ця інструкція перевіряє те, чого не видно в емуляції Chromium: справжню клавіатуру Samsung, голос, мікрофон, жести «Назад»,
пам'ять телефона й оновлення Service Worker на реальному пристрої.

**Нічого не публікується.** Реліз 263 запускається з Mac і відкривається на телефоні як `localhost` через USB.
Production (lerenbe.com, Firebase, Worker) не зачіпається. Дані на `localhost` окремі від даних на lerenbe.com, тож
справжній прогрес учня не зміниться.

## 0. Підготовка (≈ 10 хв)

**Потрібно:** Samsung з Chrome, USB-кабель, Mac з Chrome і Python 3 (є в macOS).

1. На телефоні ввімкни режим розробника: **Налаштування → Відомості про телефон → Відомості про ПЗ** → 7 разів натисни
   «Номер збірки».
2. **Налаштування → Параметри розробника** → увімкни **Налагодження USB**.
3. Підключи телефон кабелем і на телефоні дозволь налагодження для цього Mac.
4. Підготуй дві копії сайту в тимчасовій папці (у твоїй робочій папці нічого не змінюється):

```bash
git clone --quiet https://github.com/gembarskydanylo/Leren.be.git /tmp/lerenbe-226
```

```bash
git clone --quiet --branch integration/lerenbe-3.0 https://github.com/gembarskydanylo/Leren.be.git /tmp/lerenbe-263
```

5. Запусти реліз **226** (вікно терміналу не закривай):

```bash
cd /tmp/lerenbe-226 && python3 -m http.server 8080 --bind 127.0.0.1
```

6. На Mac у Chrome відкрий `chrome://inspect/#devices`:
   - натисни **Port forwarding…**;
   - додай `8080` → `127.0.0.1:8080`;
   - постав галочку **Enable port forwarding** → **Done**.

   Телефон має з'явитися в списку.
7. На телефоні в Chrome відкрий саме `http://localhost:8080/`, а не IP-адресу Mac: застосунок вмикає офлайн-режим
   і оновлення лише на `https` або на `localhost`.

Якщо сторінка не відкривається, перевір, що телефон є в `chrome://inspect` і що Chrome на Mac відкритий.

## 1. Оновлення 226 → 263 зі збереженням прогресу

1. На `localhost:8080` (реліз 226) пройди онбординг (мова інтерфейсу **українська**, мова навчання **нідерландська**).
2. Створи прогрес:
   - 2–3 уроки;
   - одна сцена LIFE;
   - відкрий хоча б один бейдж (вкладка досягнень);
   - перемкни курс на англійську й пройди 1 урок, потім поверни нідерландську.
3. **Запиши до таблиці** (розділ 9): XP, серію днів, кількість уроків, LIFE XP, бейджі з датами, мову інтерфейсу.
4. Закрий вкладку. На Mac зупини сервер 226 (`Ctrl+C`) і запусти **263** на тому самому порту:

```bash
cd /tmp/lerenbe-263 && python3 -m http.server 8080 --bind 127.0.0.1
```

5. Відкрий `http://localhost:8080/` на телефоні.

**Очікувано:**
- [ ] з'являється **одна** панель оновлення, сторінка сама не перезавантажується;
- [ ] після одного натискання «Оновити» відкривається 263;
- [ ] XP, серія днів, уроки, LIFE XP, бейджі **з тими самими датами**, мова інтерфейсу й курс такі самі, як у таблиці;
- [ ] англійський курс зберіг пройдений урок.

## 2. Перерване оновлення

1. Повтори кроки 1.1–1.4: знову 226 з прогресом. Щоб почати з нуля, у Chrome на телефоні відкрий **⋮ → Налаштування →
   Налаштування сайтів → Усі сайти → localhost → Очистити й скинути**.
2. Відкрий 263. Щойно з'явиться панель оновлення або почнеться завантаження, **увімкни режим польоту**.
3. Закрий Chrome повністю (зі списку недавніх програм) і відкрий `localhost:8080` знову, ще в режимі польоту.

**Очікувано:**
- [ ] застосунок відкривається офлайн (226 або 263), XP і прогрес на місці.
- [ ] Вимкни режим польоту й двічі відкрий застосунок: зрештою стоїть 263 і працює.
- [ ] Знову режим польоту: відкриваються головна, урок, сцена LIFE й аудіо в уроці.

## 3. Екрани й орієнтація

Перевір у портретній і **альбомній** орієнтації: головна, вибір курсу, урок (вивчення, quiz, аудіо), LIFE, нижня навігація.
- [ ] Повна назва «Lerenbe.com» у шапці, перемикач мов показує прапор і код (UK / EN / FR / AR), нічого не обрізано.
- [ ] Кнопки не перекриваються, нижня навігація не закриває відповіді, все натискається пальцем з першого разу.
- [ ] Шрифт Samsung (якщо змінено у **Налаштування → Дисплей → Розмір і стиль шрифту**) не ламає шапку й нижні підписи.

## 4. Звук і голос

- [ ] Аудіо в уроці грає з першого натискання. Повторне натискання не накладає звук.
- [ ] Голос Анастасії в LIFE.
- [ ] Крок «говоріння»: Chrome питає дозвіл на мікрофон, розпізнавання працює. Після відмови з'являється зрозуміле повідомлення.

## 5. Lexi

**Зі справжнім AI (рекомендовано).** Зупини `python3` і запусти 263 через локальне середовище Lexi з тестовим ключем
([LEXI-LOCAL-TEST.md](LEXI-LOCAL-TEST.md)). Порт і переадресація ті самі. На телефоні відкрий
`http://localhost:8080/__lexi-local`.

**Без AI.** Якщо не запускав локальне середовище, відкрий `http://localhost:8080/?lexi=demo`. Відповіді Lexi там
підписані «Demo», але інтерфейс той самий.

- [ ] Відкрий Lexi, торкнись поля вводу. **Клавіатура Samsung не закриває поле й кнопку «Надіслати»** у портреті та
      **в альбомній орієнтації** (виправлено в цьому PR).
- [ ] Жест або кнопка «Назад» закриває Lexi, а не застосунок.
- [ ] Поверни телефон під час відповіді: чат не зникає, введений текст лишається.
- [ ] Заблокуй екран на 1 хв і повернись: чат на місці.
- [ ] 20 разів відкрий і закрий Lexi: застосунок не сповільнюється, не перезавантажується.

## 10. Що ця перевірка не покриває

Ці пункти можна перевірити лише на production або після розгортання Worker:
- **Lexi через справжній Cloudflare Worker**: справжні відповіді вже перевіряються локально (крок 5), але ліміти й
  мережа Cloudflare — лише після розгортання (README розділ 3);
- **push-нагадування, вхід через Google, синхронізація й App Check**: працюють лише на lerenbe.com.

Перевіряти їх треба тестовим акаунтом, не акаунтом справжнього учня.

## 11. Прибирання

1. Зупини сервер: `Ctrl+C`.
2. У `chrome://inspect` зніми галочку **Enable port forwarding**.
3. Вимкни **Налагодження USB**.

Тимчасові копії видали, коли вони більше не потрібні:

```bash
rm -rf /tmp/lerenbe-226 /tmp/lerenbe-263
```
