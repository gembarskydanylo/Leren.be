# Посібники `/guides/` — підготовка до індексації (26.11.2026)

Рішення власника (26.11.2026): відкрити сторінку-зміст і 4 посібники для Google. Цей PR стоїть поверх PR #69
(база `audit/google-indexing-seo`): він доповнює його посилання й `tests/seo-pages.cjs`, не перезаписуючи їх.

## Що змінено

| Що | Було | Стало |
|---|---|---|
| `<meta name="robots">` | `noindex,nofollow` на 5 сторінках | прибрано |
| Підвал | «Тестова версія LerenBe» (і en/fr/ar у `guides/lang.js`) | «LerenBe · Матеріал для самостійної мовної практики» (4 мови) |
| canonical | немає | `https://lerenbe.com/guides/` і `https://lerenbe.com/guides/<файл>.html` |
| Open Graph / Twitter | немає | `og:type` (website / article), title, description, url, `og-image.jpg`, `summary_large_image` |
| `sitemap.xml` | без `/guides/` | + 5 адрес, `lastmod` 2026-11-26 |
| Посилання з головної | лише через JavaScript (`modules/home-v2`) | ще й статичні: `.seo-shell` і підвал `index.html` (поруч із посиланнями з #69) |

Дизайн, стилі, CSP сторінок, тексти посібників і `lang.js` (крім підвалу) не змінювалися.

## Доступність без JavaScript і на мобільних

- Увесь навчальний текст — у статичному HTML: кожен посібник ≈ 420 слів, зміст — вступ і 4 посилання. JavaScript
  (`guides/lang.js`) лише перекладає зміст на інші мови інтерфейсу.
- `tests/guides-browser.cjs`: 320×640, 390×844, 820×1180, 1280×800, з JavaScript і без — видимий h1 і текст,
  4 посилання на змісті, без горизонтальної прокрутки, без помилок.

## Перевірка достовірності

Перевірено за змістом (мовні факти — за граматикою нідерландської):

- `Ik kom uit Oekraïne`, `Goeiedag`, `trager` (фламандське «повільніше») — правильно.
- `half drie` = 14:30 / 02:30, «пів на третю» — правильно.
- `alsjeblieft` (ти) / `alstublieft` (ви) — правильно.
- `Je woont → Woon je?`, але `Woont u?`, `Woont hij?` — правильно.
- Застереження чесні: застосунок не замінює офіційний курс чи іспит; позначки A1.1–A2.1 не є офіційною оцінкою;
  список документів треба уточнювати в установі; для тренування — вигадані дані.

**Не вдалося перевірити (блокер середовища):** `www.vlaanderen.be` недоступний із середовища розробки (мережа
блокує з'єднання). Тому не звірено з першоджерелом речення з посібника «NT2 для початківців»:
«Офіційний ресурс Vlaanderen … називає контактні пункти: Agentschap Integratie en Inburgering, в Антверпені — Atlas,
у Генті — Amal, у Брюсселі — Huis van het Nederlands» (посібник каже, що посилання перевірено 13.11.2026).
Atlas (Антверпен) і Huis van het Nederlands (Брюссель) — відомі організації; **назву для Гента («Amal») власнику
варто звірити** на сторінці vlaanderen.be перед злиттям. Текст посібника я не змінював, щоб не замінити одне
неперевірене твердження іншим.
