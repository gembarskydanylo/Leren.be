# TEST-050 · Guided Learning → Release Candidate 273

Гілка `claude/test-050-focus-lesson`, база — `origin/main` 1312d86 (production 264). Гілка на 3 коміти попереду main і 0 позаду.
Production, Cloudflare Worker, Firebase, Firestore Rules, секрети й Google Play не змінювались. Платних AI-запитів не було.

**Вердикт: CONDITIONAL GO — для подальшого тестування на реальних пристроях, не для production.**

## Що зроблено

- **Повний керований цикл.**
  - Шлях учня: перший запуск → вибір мови курсу → знайомство з Lexi → ім'я → мета → рівень → перший урок → перевірка → (розмова, якщо готовий) → XP → підсумок.
  - Наприкінці — «Продовжити навчання» / «Завершити на сьогодні».
  - Після перезапуску Lexi пропонує наступний крок. Усе працює офлайн, без платного AI.
- **Пріоритети маршруту:**
  1. незавершений урок («Продовжити урок», жодного повторення перед ним);
  2. повторення забутих слів;
  3. новий урок;
  4. практика (розмова);
  5. підсумок.
  - Smart Calls / LIFE-дзвінки окремі й не переривають урок.
- **Критерій доступності розмови.**
  - Розмова пропонується лише тоді, коли учень уже знає ≥70 % слів сценарію: слова карток пройдених уроків плюс поточного.
  - Новий учень (10 %) отримує лише урок; після 3 уроків першої теми (80 %) з'являється розмова.
  - Відповіді в розмовах A1.1 — не довші за 3 слова.
  - **Обмеження:** 70 % — технічне правило за лексикою, а не доказ педагогічної відповідності. Граматика сценарію та обов'язкові фрази ним не перевіряються (див. «Не готово»).
- **EN / FR (бета).**
  - Перший запуск, власний ключ прогресу `leren_path_v1@en` / `@fr`.
  - Спільні XP, повернення після закриття.
  - Прогрес мов не змішується, нідерландський маршрут не чіпається.
  - Обмеження позначено чесно, з даних: англійська — 72 уроки (1.1–1.2), французька — 36 (1.1). Примітка на «Сьогодні»: повторення помилок і розмови з Lexi поки лише в нідерландському.
- **Ім'я.**
  - Показ, зміна, видалення; пропуск не блокує навчання.
  - Імена українською, французькою, англійською й арабською з ізоляцією напрямку тексту.
  - Ім'я показано один раз (без повтору в репліці Lexi).
  - Ім'я не синхронізується, не потрапляє в резервні копії й не читається кодом AI/Lexi/Worker. Worker не змінювався.
- **Кнопка «Назад» Android у уроці** працює як ✕: повертає на «Сьогодні» зі збереженим місцем. У production 264 вона виводила із застосунку. Вікно Lexi поверх уроку закривається першим.
- **Міграція 264 → 273** зі справжнім Service Worker — 8 профілів, усі PASS:
  - новий учень; половина курсу; великий прогрес з EN/FR і датованими нагородами; пошкоджене сховище; навчання офлайн (французький інтерфейс); повернення після перерви (арабський);
  - **незавершений урок у 264** → «Продовжити урок», те саме місце, темна тема й голос збережені;
  - **несумісна сесія** → безпечне відновлення: відкривається дійсний урок, пройдені уроки збережені.
  - Старі кеші видаляються, після оновлення показано новий інтерфейс.
