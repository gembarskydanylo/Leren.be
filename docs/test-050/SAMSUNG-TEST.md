# TEST-050 · Перевірка на Samsung

Тестова збірка «Сьогодні з Lexi» (B + C). Гілка `claude/test-050-guided-app`, основа — production `main` 264 (1312d86).
Кеш Service Worker: `leren-be-v270`. Production, Cloudflare Worker і Firebase не змінювались.

## Посилання

Сервер на Mac: `python3 -m http.server 8350 --bind 127.0.0.1` у теці worktree.

**Варіант 1 — кабель USB (рекомендовано, працює офлайн-режим):**

```bash
~/Library/Android/sdk/platform-tools/adb devices
```

```bash
~/Library/Android/sdk/platform-tools/adb reverse tcp:8350 tcp:8350
```

На телефоні в Chrome: **http://localhost:8350/**

Service Worker реєструється тільки на `https:` або `localhost`, тому офлайн перевіряється лише в цьому варіанті.

**Варіант 2 — та сама Wi-Fi мережа (без офлайну):** перезапустити сервер з `--bind 0.0.0.0` і відкрити `http://<IP Mac>:8350/`.
Service Worker тут не працює, тому офлайн-пункти пропустити.

Щоб почати як новий користувач: Chrome → ⋮ → Налаштування → Налаштування сайтів → Усі сайти → localhost:8350 → Очистити.
Дані production-сайту lerenbe.com це не зачіпає: це окремий origin.

## Що перевірити на телефоні

Новий користувач
1. Онбординг 5 кроків: мова → ім'я (можна пропустити) → цілі → рівень → час і темп. Клавіатура не закриває поле імені й кнопку «Далі».
2. «Почати» одразу відкриває урок, а не каталог.
3. Після уроку: «Крок 1 з 2 готово», XP, автоперехід через 3 с; «Пауза» зупиняє відлік.
4. Практика (розмова з 3 реплік) → кнопка внизу → «Заняття завершено»: XP, досягнення, наступний крок, «Продовжити навчання».
5. Ім'я в привітанні й у бульбашці Lexi написане правильно (кирилиця, латиниця, арабська).

Існуючий користувач (з прогресом, без імені)
6. Онбординг не з'являється, прогрес, XP, серія й голос ті самі.
7. Картка «Як мені до тебе звертатися?» → «Пізніше» → після перезапуску не з'являється.
8. Ще → Профіль: змінити ім'я, темп, мету; видалити ім'я.

Відновлення й XP
9. Закрити застосунок посеред уроку → відкрити → «Продовжи» веде в той самий урок.
10. Повернутися «Назад» після завершеного кроку: XP не нараховується вдруге.

Офлайн (лише варіант 1)
11. Відкрити один раз онлайн, дочекатися завантаження → режим польоту → перезапустити → головна, Lexi-аватар і урок працюють, XP зберігається.

Інтерфейс
12. Головна вміщується в один екран: кнопка «Почати навчання» видна над нижньою панеллю без прокрутки.
13. Нижня панель: Сьогодні / Навчання / Lexi / Ігри / Ще; «Ще» відкриває словник, прогрес, іспити, LIFE, годинник, вільні вправи, налаштування.
14. Мови uk / en / fr / ar; арабська — справа наліво, кнопки й бульбашки віддзеркалені.
15. Темна тема, великий шрифт системи (Samsung: Налаштування → Дисплей → Розмір шрифту), жест «Назад» Android.
16. Lexi на головній: без інтернету — підказка «потрібен інтернет», без помилок.

## Відомі обмеження прототипу

- Ім'я не передається в AI-запити Lexi, навіть зі згодою: для цього потрібна зміна Cloudflare Worker, а її в цій задачі заборонено. Згода зберігається на пристрої.
- Повторення (review) з'являється в сесії лише тоді, коли є ≥ 3 слова до повторення.
- Хвилини «мети дня» рахує наявний лічильник часу застосунку (реальний час на екрані), а не оцінка кроків.
- Після практики кнопка зведення розмови ще має стару назву «До наступного уроку», хоча веде до підсумку сесії.
- Курси англійської й французької залишаються зі старою головною (Today увімкнено лише для нідерландської).
