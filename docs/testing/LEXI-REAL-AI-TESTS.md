# Lexi — перевірка зі справжнім AI (реліз 264)

Mock-тести перевіряють код Worker і застосунку, але не те, як справжня модель заповнює `reply_type`, `explain` і чи тримає правило Lesson Help. Це перевіряє лише справжній AI.

Статус на 2026-11-22: **NOT RUN** (платні запити потребують окремого дозволу власника). Сухий прогін на mock-сервері: усі запити HTTP 200.

## Вартість і безпека

- **31 виклик моделі** у наборі 264 + ≈ 16 у загальному наборі. Модель — за замовчуванням Worker (`claude-haiku-5-5`).
- Потрібен **тестовий** ключ Anthropic з лімітом витрат (console.anthropic.com → API keys / Limits). Не production-ключ.
- Ключ вводиться прихованим полем у `tools/lexi-local.cjs`: не друкується, не пишеться у файл, не надсилається в чат.
- Production Worker і його квота не використовуються: Worker із гілки працює локально.

## Запуск

1. Порт 8080 має бути вільний. Запусти локальне середовище в папці гілки (див. [SAMSUNG-264.md](SAMSUNG-264.md), розділ 0, як отримати `/tmp/lerenbe-264-check`):

```bash
cd /tmp/lerenbe-264-check && node tools/lexi-local.cjs
```

2. У другому вікні — набір релізу 264:

```bash
cd /tmp/lerenbe-264-check && LEXI_SET=264 node tools/lexi-live-check.cjs lexi-live-264.md
```

3. Загальний набір (необов'язково):

```bash
cd /tmp/lerenbe-264-check && node tools/lexi-live-check.cjs lexi-live-general.md
```

Між запитами пауза 5,5 с (ліміт Worker 12 запитів на хвилину на пристрій), тож набір 264 триває ≈ 3–4 хв.

## Помилки Worker і що бачить учень

Перевірено mock-тестами (`tests/ai-worker-limits.cjs`, `tests/v3/suite/lexi-reliability-043.cjs`, `lexi-engine.cjs`). Під час живого прогону записати, якщо щось із цього трапиться:

| Відповідь Worker | Коли | Застосунок | Квота |
|---|---|---|---|
| 429 `slow`, `Retry-After: 60` | > 12 запитів / хв з пристрою, > 40 з мережі або > 300 загалом | «Зачекай хвилинку», кнопка повтору | Не списується |
| 429 `limit`, `scope: device` / `network` | 60 відповідей за день на пристрій / 150 на мережу | Коли можна знову (час скидання) | — |
| 502 `ai` / `format` / `refusal` | Помилка моделі, зламаний JSON, відмова | «Спробуй ще раз», без зависання | Повертається |
| 504 `timeout` | Модель не відповіла за 25 с (застосунок чекає 30 с) | «Спробуй ще раз» | Повертається |
| 503 `off` | Аварійний вимикач `AI_OFF=1` | «Lexi зараз недоступний» | — |
| 403 `forbidden` | Чужий Origin | «Lexi зараз недоступний» | — |

## Критерій для злиття

- Lesson Help до відповіді: **0** видач розв'язку (5 сценаріїв).
- **0** відповідей від імені Peter або Dafna.
- Щонайменше **26 з 31** сценаріїв мають правильну кнопку (`reply_type`).
- Пояснення мовою інтерфейсу є в усіх 10 сценаріях «питання про мову».

Позначки CHECK у звіті — евристики. Остаточну оцінку дає прочитання відповідей. Звіт (`lexi-live-264.md`) не комітити, якщо в ньому є персональні дані; ключа в ньому немає.

Після перевірки зупини сервер (Ctrl+C) і, за бажанням, видали тестовий ключ у консолі Anthropic.
