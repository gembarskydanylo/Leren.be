# Помаранчевий кіт — набір для Telegram

У папці є 240 прозорих PNG-зображень у двох форматах:

- custom-emoji/ — 100 × 100 px для custom emoji.
- stickers/ — 512 × 512 px для статичних стікерів.

Telegram приймає статичні custom emoji у PNG або WebP розміром рівно 100 × 100 px. Для статичних стікерів потрібен прозорий PNG або WebP, один бік має бути 512 px. Ці файли підготовлені у форматі PNG. Див. [вимоги Telegram](https://core.telegram.org/stickers) та [імпорт стікерів](https://core.telegram.org/import-stickers).

## Як завантажити

1. В Telegram відкрий [@Stickers](https://t.me/stickers).
2. Створи набір custom emoji або sticker pack і вибери відповідний формат.
3. Завантаж файли з відповідної папки. Назви файлів лишені однаковими в обох папках.
4. Для кожного файла признач стандартний emoji-тригер за manifest.csv.
5. Опублікуй набір через бота й відкрий посилання на нього, щоб додати у свій Telegram.

Використання custom emoji-наборів у чатах залежить від тарифу Telegram; без Premium файли з stickers/ можна додати як звичайний набір стікерів.

manifest.csv містить назву файла, рекомендований emoji-тригер і назву ілюстрації. У різних котячих настроїв може бути однаковий рекомендований тригер.
